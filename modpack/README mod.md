## Recommended Modpack for better fps

To ensure the best performance and smooth frame rates while running both games simultaneously, a pre-tested collection of optimization mods is included directly in this repository in the `modpack/mod` folder (includes **Sodium**, **Lithium**, **FerriteCore**, and other tweaks).

### How to use:
1. Open the `fps-modpack` folder from this repository.
2. Copy all `.jar` files inside it into your Minecraft `.minecraft/mods/` directory alongside Ultracraft and Fabric API.
3. Launch Minecraft 1.21.11 using **Fabric Loader**.
